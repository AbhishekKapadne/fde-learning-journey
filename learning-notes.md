
# My Git Learning Notes

## What I Learned

1. Git tracks changes in my code.
2. GitHub stores my code online.
3. A repository contains project files.
4. A commit saves a snapshot of changes.
5. A branch allows me to work on features separately.
6. A merge combines changes from different branches.
7. A pull request allows others to review my changes.

## Commands I Practised

- git status
- git add
- git commit
- git push
- git pull
- git branch
- git switch
- git merge
